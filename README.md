# 🛠️ KIVIK Python Tools

Simple Python programs and console games to learn coding basics.

---

## 📂 Projects

### 🧟‍♂️ 1. Dying Light Game
* **File:** `dying_light_game.py` / `dy_simulator.py`
* **Description:** A simple text-based game based on *Dying Light*. Includes safe zones, day/night time, easy fighting, and inventory items.

### 🧮 2. Calculator
* **File:** `calculator.py`
* **Description:** A simple terminal calculator for basic math (+, -, *, /) with simple error checks.

### ❓ 3. Quiz App
* **File:** `quiz_application.py`
* **Description:** A simple Python quiz program made with OOP. It asks questions, checks answers, and shows your score at the end.
